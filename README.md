# GCT — distribution Mac

Dépôt **public** servant uniquement à distribuer l'application GCT pour macOS :
le flux de mise à jour (`appcast.xml`) et les binaires des releases.

Le code source vit ailleurs, dans un dépôt privé.

## Installer

Télécharger `GCT.dmg` depuis la [dernière release](https://github.com/WelldoneStudioAI/gct-dist/releases/latest),
l'ouvrir, glisser **GCT** dans **Applications**, double-cliquer.

L'application est signée et notarisée par Apple : aucun avertissement de sécurité,
aucun réglage à faire. Elle se met à jour toute seule par la suite.

Prérequis : **macOS 26** ou plus récent.
